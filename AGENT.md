# Задание для нейронки: развернуть VPN Gate на этом Windows

Прочитай этот файл целиком и выполни его на компьютере пользователя. Не выдумывай другие VPN, не ставь Amnezia и не поднимай второй профиль SoftEther.

Папка, в которой лежит этот файл, — комплект установки. Рядом есть `install.ps1`, `README.md` и `payload\`.

## Что должно получиться

1. Установлен SoftEther VPN Client 4.44 Build 9807. Плагин VPN Gate входит в этот клиент, отдельно его не скачивать.
2. Скрипты и TrafikRuler лежат в `C:\ProgramData\VPNGateSetup`.
3. На рабочем столе три ярлыка: «VPN Gate — Включить / Выключить / Статус» и ярлык TrafikRuler.
4. При входе в Windows сама запускается задача `VPNGateKeepGateways`. Она возвращает шлюз на физические адаптеры. Без неё правило TrafikRuler «только Wi-Fi» оставляет программу без интернета: SoftEther стирает этот шлюз.
5. VPN сам не подключается. Подключение делает человек.

Проверка, что схема живая: VPN включён, сайт в браузере без правила открывается через зарубежный IP, а программа с правилом TrafikRuler на Wi-Fi открывает сайт через обычный домашний интернет.

## Чего не делать

- Не подключать одновременно профиль из ярлыка «Включить» и профиль, который человек поднял кнопкой VPN Gate в графическом клиенте. Второй туннель рвёт первый.
- Не запускать `route-guard.ps1` и не вешать маршруты по IP отдельных программ. На Windows так нельзя развести две программы, если они ходят на один адрес. Для этого здесь TrafikRuler.
- Не ставить флаг `/NOTRACK` на профиль, который создал плагин VPN Gate. Клиент отвечает ошибкой 145 и велит править его только утилитой VPN Gate.
- Не подставлять шлюз `0.0.0.0`. Такой маршрут глушит сеть.
- Не выключать уже работающий VPN пользователя, пока он сам не попросил.

## Шаги

1. Запусти от администратора:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

Скрипт сам запросит права. Он копирует файлы, ставит клиент SoftEther 4.44, если `vpncmd_x64.exe` ещё нет, ставит .NET 8 Desktop Runtime, если его нет, создаёт ярлыки и задачу.

Адреса скачивания, если придётся качать вручную:

- Клиент: `https://github.com/SoftEtherVPN/SoftEtherVPN_Stable/releases/download/v4.44-9807-rtm/softether-vpnclient-v4.44-9807-rtm-2025.04.16-windows-x86_x64-intel.exe`
- Зеркало, если GitHub недоступен: `http://www.softether-download.com/files/softether/v4.44-9807-rtm-2025.04.16-tree/Windows/SoftEther_VPN_Client/softether-vpnclient-v4.44-9807-rtm-2025.04.16-windows-x86_x64-intel.exe`
- .NET 8 Desktop: `https://aka.ms/dotnet/8.0/windowsdesktop-runtime-win-x64.exe`

В мастере SoftEther выбирать VPN Client, не Server и не Bridge.

2. Убедись, что существует файл:

`C:\Program Files\SoftEther VPN Client\vpncmd_x64.exe`

или тот же файл в `Program Files (x86)`. Служба SoftEther VPN Client должна быть запущена.

3. Попроси человека один раз открыть SoftEther VPN Client Manager и подключиться через встроенный VPN Gate к публичному шлюзу. Это основной способ. Ярлык «VPN Gate — Включить» — второй способ, тем же клиентом, своим профилем `VPNGATE_AUTO`. Одновременно с графическим подключением его не нажимать.

4. Запусти TrafikRuler от администратора. Для программы, которой нужен обычный интернет, а не VPN, добавь правило: exe этой программы и физический адаптер (Wi-Fi или кабель), на котором есть домашний шлюз. Остальные программы не добавляй: они пойдут в VPN.

5. Проверь:

```powershell
Get-NetRoute -DestinationPrefix '0.0.0.0/0' -PolicyStore ActiveStore |
  Select-Object InterfaceAlias, NextHop, RouteMetric
```

Должен быть маршрут через адаптер `VPN - VPN Client` и маршруты через физические адаптеры с NextHop домашнего роутера. Маршрут VPN предпочтительнее.

```powershell
Find-NetRoute -RemoteIPAddress 1.1.1.1
```

Без правила TrafikRuler этот адрес должен выбираться через VPN-адаптер.

Попроси человека открыть сайт в программе с правилом и в программе без правила. У программы с правилом исходящий IP домашний, у остальных — адрес шлюза VPN Gate.

## Если что-то сломалось

- Правило TrafikRuler включено, а у программы нет интернета: не запущен `keep-gateways.ps1` или у выбранного адаптера нет своего шлюза. Запусти скрипт от администратора и выбери в правиле тот адаптер, которым компьютер реально выходит в интернет без VPN.
- Весь интернет пропал после выключения VPN: SoftEther оставил единственным маршрутом мёртвый VPN-адаптер. Запусти ярлык «Выключить» или удали `0.0.0.0/0` на отключённом VPN-адаптере. `keep-gateways.ps1` после этого снова кладёт физические шлюзы.
- Два VPN-адаптера и оба пытаются быть маршрутом по умолчанию: отключи один профиль. Рабочая схема — один туннель.
